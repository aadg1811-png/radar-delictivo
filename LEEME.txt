RADAR DE TENDENCIAS DELICTIVAS - Tablero Streamlit (TPI Grupo 10)

Archivos de esta carpeta
  app.py                        Codigo del tablero
  Dataset_snic_limpio.csv       Datos limpios (los exporta el notebook, Cap. 2)
  provincias_argentina.geojson  Limites de las 24 provincias para el mapa
  requirements.txt              Librerias necesarias
  abrir_tablero.bat             Atajo para Windows (doble clic)

Requisito: Python 3.10 o superior (python.org). Al instalarlo, tildar "Add python.exe to PATH".

Forma rapida (Windows): doble clic en abrir_tablero.bat

Forma "a mano" (VS Code o cualquier terminal), parado en esta carpeta:
  python -m pip install -r requirements.txt
  python -m streamlit run app.py
Se abre solo en el navegador en http://localhost:8501
Para cerrarlo: Ctrl + C en la terminal.

Para tener un link publico (para la entrega o el video):
  1. Subir esta carpeta a un repositorio de GitHub.
  2. Entrar a share.streamlit.io con la cuenta de GitHub > Create app > elegir el repo y app.py > Deploy.
